# Документація до проєкту 

## Використані технології та інструменти

### Мова програмування

- **Python 3.13**: Основна мова для розробки серверної логіки та роботи з базою даних.

### Фреймворки та бібліотеки

- **Flask 3.1.0**: Легкий вебфреймворк для створення HTTP-маршрутів, обробки запитів і рендерингу шаблонів.
- **SQLAlchemy 2.0.40**: ORM-бібліотека для роботи з базою даних SQLite, створення моделей і виконання CRUD-операцій.
- **Jinja2**: Шаблонізатор, інтегрований із Flask, для створення динамічних HTML-сторінок.
- **datetime**: Вбудована бібліотека Python для валідації дат у бізнес-логіці.

### База даних

- **SQLite**: Легка вбудована база даних для зберігання інформації про номери та бронювання.

### Інструменти розробки

- **PyCharm Professional**: IDE для написання, дебагінгу та запуску коду. Використовувався для налаштування віртуального середовища, управління залежностями та роботи з Git.
- **Git**: Система контролю версій для збереження коду в репозиторії.
- **GitHub**: Платформа для хостингу репозиторію та документації.
- **DB Browser for SQLite**: Інструмент для перегляду та перевірки вмісту бази даних `hotel.db`.

## Реалізований функціонал

- **Список бронювань**: Таблиця з ID, ім’ям гостя, датою заїзду.
- **Створення бронювання**: Форма з валідацією (дати, поля, номери).
- **Перегляд**: Деталі бронювання (гість, дати, номер).
- **Редагування**: Оновлення даних із валідацією.
- **Видалення**: Видалення з підтвердженням.
- **Повідомлення**: Успіх або помилки (наприклад, "Некоректна дата").
